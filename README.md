# Void-Ai 🚀

An **ultra-modern, desktop AI companion** designed for developers, students, and everyday productivity. Powered by Python and PyQt6 with Fluent Design elements, Void-Ai delivers a fluid UI/UX for coding, learning, and conversation—completely powered by flexible free and open API providers.

---

## ✨ Features

* **Ultra UI/UX Experience**: Sleek Fluent Design with dark-glass aesthetics, smooth animations, dynamic visuals, and responsive layouts.
* **Multi-Provider AI Routing**: Seamlessly integrate **Groq AI**, **OpenRouter AI**, and **Ollama Cloud** (utilizing free & open API tiers).
* **Smart Model Roles**: Assign distinct AI models to **Fast**, **Flash**, and **Complex** tasks.
* **Specialized Chat Modes**: Built-in context presets including **"A Friend"**, **"Dev Helper"**, and **"Learn Zone"**.
* **Code Block Utilities**: Custom syntax highlighting with single-click copy functionality.
* **Persistent Memory & Multi-Chat**: Pin, rename, and manage multiple concurrent chat histories stored locally on your device.
* **Developer Diagnostics**: Built-in System Logs tab for real-time API call inspection and debugging.

---

## 🔒 Security & Privacy First

* **Local API Key Storage**: All API keys and preferences are stored locally on your machine (`appdata.json` / `apidata.json`).
* **No Middleware**: Direct client-to-provider communication ensures your keys and data are never sent to third-party tracking servers.

---

## 🛠 Tech Stack & Development

* **Language**: Python 3.10+
* **UI Framework**: PyQt6 & QFluentWidgets
* **Architecture**: Asynchronous QThread workers, custom QPainter components, local persistence layer.
